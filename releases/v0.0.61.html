Release v0.0.61

Week of August 31, 2026

Release schedule

  • Internal release: Thursday, September 3, 2026
  • Testing: Friday, September 4 through Sunday, September 6, 2026
  • Public release: Monday, September 7, 2026

This release makes 3DVR easier to use and more useful. Operator can understand screenshots. The Portal can remember useful information. Our servers and workers are more reliable. Freelancer Desk can handle more of the work day. Show-Tech can turn regular computers into AV control and output nodes. Our business tools can also remember what worked before they try the next step.

  • Operator can understand screenshots. Operator can now accept screenshots, including messages that only contain an image. It shows when it is busy, works better on small phone screens, and has a full live test for the mobile flow. See PR #2123.
  • The Portal can remember useful information. Digital Organism now gives the main 3DVR agent local memory. It can remember, recall, correct, and forget saved information. It can also bring in approved notes from Context HQ. Personal memory stays local until a user picks a backend that may use it. See PR #2113, PR #2114, PR #2116, and PR #2118.
  • Operator can safely test editing code. We now have a real test for the owner-only Operator → Forge edit path. The test signs a request, makes a harmless code change, pushes it to a throwaway Git repo, and checks that the change really landed. This proves the path works without opening up production access. See PR #2124.
  • Servers and workers are more reliable. Agent jobs now use a durable SQLite queue. Workers can recover from some failures. OVH has separate areas for production, workspaces, and development. Our cloud servers also have better SSH links, and phones or laptops can join the mesh more easily. See PR #2038, PR #2048, PR #2058, PR #2061, and PR #2104.
  • Freelancer Desk can handle more of the work day. Freelancer Desk can track clients, possible jobs, booked gigs, payments, schedules, and simple notes about facts, decisions, and actions. It also has private browser workspaces for websites that do not have a good API, plus a Growth Autopilot service path. See PR #2034, PR #2037, PR #2039, PR #2043, PR #2062, PR #2071, and PR #2072.
  • Regular computers can become Show-Tech AV nodes. A computer can now join a Show-Tech network, report what it can do, receive timed cues, and play or route audio and video. We added cloud sync, GStreamer output, PipeWire audio control, and a simple logical AV patchbay. See PR #2067, PR #2068, PR #2069, PR #2070, and PR #2073.
  • Business tools can remember what worked. Launch Room can send ideas into Projects. Projects can send work to Web Builder and Growth Operator. Customer wins can become proof of delivery. The local-business website system can also handle more of the path from lead to paid work. Money Printer now keeps notes about past results before it plans the next move. See PR #1980, PR #1982, PR #1984, PR #1985, PR #1988, PR #2074, and PR #2100.
  • 3DVR is getting easier to teach and stays open. Teach can turn a screen demo and narration into a skill draft that a person reviews before using. We also made the agent's levels of freedom clearer. The long-term plan still keeps the core product free and open, while charging for real services and real operating costs instead of locking features away on purpose. See PR #2015, PR #2016, and PR #2115.

Safety

Personal memory stays local until the user chooses a backend that may use it. Only the approved owner can use the Operator → Forge edit path. The self-edit test uses temporary keys and a throwaway Git repo. Freelancer browser workspaces stay private to the local machine by default. Show-Tech only accepts known AV commands, not any shell command. Outreach still uses public information, sending limits, do-not-contact rules, and human review for phone leads.

In short

v0.0.61 is the internal Thursday release for this week. We test it Friday through Sunday, then make the stable public release on Monday. It brings better screenshots, memory, self-edit testing, server reliability, freelancer tools, AV networking, and smarter business automation.
