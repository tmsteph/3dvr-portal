Release v0.0.61

Week of August 31, 2026 · Release Candidate

Release phase

  • Introduced: Thursday Dev Meeting — September 3, 2026
  • Test and stabilization window: September 4–6, 2026
  • Planned technical release: Monday, September 7, 2026

This week, 3DVR pulled more of the system into one coherent loop. Operator can see screenshots and prove its self-edit path, the Digital Organism now supplies durable local memory to the canonical agent, server and workspace infrastructure is more resilient, freelancers gained a real working environment, Show-Tech became an implementation-backed network AV system, and the autonomous business stack learned to use evidence before repeating work.

  • Operator became a real multimodal control surface: Operator now accepts screenshot attachments and screenshot-only turns, shows a visible busy state, keeps the mobile header usable, and has a full live production acceptance test covering the 390px mobile flow, screenshot understanding, attachment cleanup, and API/browser failures. See PR #2123.
  • Digital Organism became the Portal's durable local memory layer: the canonical apps/agent runtime now owns append-only remember/recall/correct/forget memory, imports deliberate Context HQ handoffs with provenance, retrieves memory locally before task construction, and continuously syncs approved handoffs on the worker. Memory-bearing execution requires an explicit backend rather than silently choosing a provider. See PR #2113, PR #2114, PR #2116, and PR #2118.
  • Self-editing moved from concept toward proved machinery: the difficult owner-only Operator → Forge path now has an integration test that signs a real request, runs the real authorization and worker logic, commits and pushes a harmless canary to a disposable remote, and verifies independently that the edit landed. See PR #2124.
  • The agent runtime became more infrastructure-grade: production task execution gained a transactional SQLite queue with claim renewal and recovery, safer isolated workers and health probes, while OVH gained protected production/workspace/dev resource lanes. The cloud core now has dedicated SSH mesh paths and roaming-device joins for Termux and Linux laptops. See PR #2038, PR #2048, PR #2058, PR #2061, and PR #2104.
  • Freelancer Desk grew into an actual work operating system: Freelancer Desk now connects client relationships, opportunity stages, gigs, invoicing/payment state, schedule protection, and a lightweight fact/decision/action ledger. Isolated persistent browser workspaces add a compatibility path for sites without useful APIs, and Freelancer Growth Autopilot adds a recurring managed-service path. See PR #2034, PR #2037, PR #2039, PR #2043, PR #2062, PR #2071, and PR #2072.
  • Show-Tech became implementation-backed AV infrastructure: ordinary computers can now act as authenticated capability-advertising AV nodes with local cue scheduling, multi-node cloud synchronization, native GStreamer playback/test output, PipeWire/WirePlumber audio control, and a logical program audio/video patchbay. See PR #2067, PR #2068, PR #2069, PR #2070, and PR #2073.
  • The launch and business loops started closing on evidence: Launch Room briefs can become Projects, Projects can hand work to Web Builder and Growth Operator, customer wins can become delivery proof, and the local-business website loop now supports hosting-safe upgrades, first-site launches, campaign-aware replies, paid fulfillment, better lead routing, and quieter operator alerts. Money Printer also remembers operation outcomes before planning more work. See PR #1980, PR #1982, PR #1984, PR #1985, PR #1988, PR #2074, and PR #2100.
  • 3DVR clarified how it learns and grows: the new Teach flow turns local screen/narration demonstrations into review-first skill drafts, the autonomy ladder now lives with the canonical agent, and the roadmap explicitly favors an excellent free/open core while charging for scarce human effort, managed convenience, and real operating costs rather than artificial lock-in. See PR #2015, PR #2016, and PR #2115.

Safety notes

Digital Organism recall and context construction remain local, and memory-bearing execution requires an explicit provider/backend before personal context leaves the machine. Operator/Forge write authority remains signed and owner-bound; the self-edit acceptance path uses temporary credentials and a disposable remote rather than weakening production authority. Freelancer browser workspaces remain isolated and loopback-only by default, and external schedule/account changes are not silently performed. Show-Tech mutations remain authenticated and native AV uses fixed structured commands instead of exposing arbitrary shell execution. Outreach retains public-information-only research, quality gates, caps, do-not-contact handling, and review-only phone routes rather than automated calling.

What this candidate covers

v0.0.61 is the weekly milestone candidate for the week of August 31, 2026. It summarizes the major Portal, Operator, Digital Organism, agent-runtime, infrastructure, freelancer, Show-Tech, launch-loop, and autonomous business work merged after v0.0.60 through September 3. The candidate is introduced at the Thursday dev meeting, soaked and stabilized through the weekend, and should be marked as the official latest release on Monday only if the release gates remain green.
