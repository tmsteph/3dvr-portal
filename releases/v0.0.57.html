Release v0.0.57

Week of August 3, 2026

This release strengthens the portal’s shared nervous system. Money Printer now has an evidence-backed Opportunity Inbox with encrypted account sync and guarded first-party intake; Chat gains durable cross-browser delivery and real server-backed notifications; and Life Space feels more like a touch-native visual canvas. The CRM migration path also preserves the portal’s existing history before it moves into canonical Postgres records.

  • Opportunity Engine: the new Opportunity Inbox ranks demand with visible evidence, economics, confidence, permission, and a human-reviewed next action. Records remain useful locally, sync encrypted for signed-in users, and deduplicate email replies, portal forms, and manual forwards through PR #1266 through PR #1270.
  • Reliable Chat and notifications: Chat hardened guest rendering, added standards-based closed-app Web Push, verifies notification delivery through the live server, keeps long links inside mobile screens, and reconciles messages durably between browsers. Dead relay paths are quarantined in PR #1274, PR #1275, PR #1277 through PR #1282, and PR #1288.
  • Touch-native Life Space: Life Space keeps body panning continuous on real touchscreens, attaches drawings to cards, preserves world ink separately, and adds two-finger pinch zoom and pan. Operator and Life Space are also easier to find from portal search through PR #1256 through PR #1259, PR #1280, and PR #1287.
  • Lossless CRM foundation: the Postgres migration now defaults to a safe dry run, creates canonical contacts and activities, retains raw source records, and avoids triggering outreach. The historical verification preserved 42 lead rows, linked all 17 activities, and retained all 59 raw rows in PR #1283.
  • Portal feel: the home spinner reacts more playfully to pull distance and swipe momentum while remaining bounded in PR #1289.

Trust boundaries

Opportunity responses still require human review, the CRM migration performs no outreach, and Chat keeps server acceptance separate from physical-device notification proof. The latest live bidirectional Chat check delivered every test message without refresh, while its measured p95 was 2.13 seconds, so this release does not claim a universal sub-two-second result.

Release cadence

v0.0.57 covers the merged portal work completed after the v0.0.56 cutoff at PR #1254 and brings the public release history through PR #1289.
