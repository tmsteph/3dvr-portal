Networked AV system

Show-Tech

Show-Tech is an open 3DVR project for turning ordinary computers into networked audio-video control and output nodes.

Join the show

A computer can identify itself, report what it can do, and join the Show-Tech network.

Run timed cues

Nodes can receive structured show commands and execute actions at the right time.

Play and route media

The current work includes GStreamer playback, PipeWire audio control, and a logical AV patchbay.

Stay controlled

Show-Tech accepts known AV commands rather than opening a general remote shell.

Where it is today

Show-Tech is still an early working system. The goal is a simple, open way to make computers useful as playback, routing, control, and output nodes across a show network.
