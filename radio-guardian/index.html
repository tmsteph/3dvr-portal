Radio Guardian

Offline-first radio automation for Samsung Galaxy Fold. Free, open-source design; no ads, telemetry, or subscriptions.

Configuration prototype

How it will work

Using phone: screen unlock requests normal connectivity. Pocket: screen off + proximity + grace period requests airplane mode. Periodic checks: briefly reconnect, then return offline. Wi-Fi: prefer Wi-Fi and disable cellular modem only if privileged controls support it.

Not active on this phone yet. This web page only saves a configuration prototype. Android requires a native app and user-authorized privileged integration (potentially Shizuku or root) to toggle airplane mode; ordinary browser pages cannot change radios.

Airplane mode prevents incoming cellular calls and texts until reconnecting. Emergency calling may require manually restoring cellular service. Never interrupt active calls, navigation, tethering, or user override. Notification arrival and exact timing are not guaranteed.

Implementation plan

  1. Native Kotlin app with local settings, screen/proximity events and state machine.
  2. Privileged radio adapter with explicit capability checks and verified actual radio state; no simulated success.
  3. Alarm scheduling, wake/unlock priority, overrides, reboot recovery, and safe failure modes.
  4. Samsung Fold physical-device testing before enabling automatic airplane mode.
RF exposure reduction is the design goal, not a claim of proven health benefit.
