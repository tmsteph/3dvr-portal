# Contributing to the 3DVR Open Split Keyboard

You do not need to be an electrical engineer to contribute.

## Good first contributions

- Find two or three controller options and compare cost, availability, documentation, and firmware support.
- Find an existing open split-keyboard PCB that could reduce V0 risk.
- Propose a simple, conservative layout for the first prototype.
- Identify printable open cases or case-design references.
- Compare switch options for price, availability, repairability, and typing feel.
- Improve the BOM with exact part numbers and alternates.
- Write beginner-friendly soldering or flashing instructions.
- Test the documentation by trying to reproduce a step without private help.
- Photograph builds and failures clearly.
- Document a repair or replacement procedure.

## Contribution standard

Prefer evidence over preference. When recommending a part or design choice, include the reason: price, availability, license, dimensions, compatibility, repairability, test result, or other reproducible constraint.

## Community rule

If you learn something while building — especially something that went wrong — document it so the next person starts one step ahead.
