Bitwarden Secrets Manager

Set up machine access

Create a Bitwarden Secrets Manager machine account with access only to the 3DVR Agent project, then paste its access token here once.

This goes over HTTPS straight to the OVH control plane, is stored in the broker's root-only config, and is never echoed back. Do not paste it into chat.
