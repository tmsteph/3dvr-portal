# Calendar UI v2

This branch is intentionally a development-only calendar UX pass.

Goals:
- Make the month grid the dominant desktop surface.
- Remove nested desktop sidebars that squeeze the month into horizontal scrolling.
- Keep adding an event one click away without permanently occupying calendar width.
- Move sharing, connections, and imports below the month as secondary tools.
- Hide manual OAuth token entry and other advanced controls behind disclosure elements.
- Preserve the seven-column mobile month view and compact mobile time labels.

Production should not be changed until the Vercel preview is browser-tested on desktop and phone-sized viewports.
