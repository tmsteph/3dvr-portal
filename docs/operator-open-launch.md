## Promise
We host your agent. You get things done.
Hosted-first for people who need outcomes; open source and self-hosting remain available to builders.

## Shipped in this launch
- Mobile-first public introduction connected to the existing Operator.
- Three starters use the existing sessionStorage prefill contract, with submit:false.
- Private, durable hosted-pilot intake in the existing server queue; receipt-only public responses, consent and anti-spam protections. No account, agent, subscription or payment is activated by joining.
- GitHub public contribution link; native share / clipboard fallback.
- Canonical URL and social metadata; discovery from Operator, README and sitemap.

## Existing foundation
Operator already implements chat, conversation branches, saved-history sync, workspace actions, and tracking of delegated jobs. Access and provider configuration affect what a visitor can do. This launch does not claim universal autonomous execution is complete.

## Next milestone: one real overnight loop
Acceptance: submit a bounded project from mobile; persist its job and authorization on the server; close the phone; survive worker restart; produce a checked artifact with status, cost and any decision needed. Reopen from another device and inspect the same result.
Extend existing operator-runtime, apps/agent and Workboard. Reuse the current worker service. Do not create an unrelated assistant backend.

Required checks: task persistence/recovery, credential scoping, budget enforcement, duplicate execution protection, cancellation and result delivery. Describe model provider data boundaries. Portable user memory and open-model parity remain milestones until verified.

## Audience and growth
Lead with people who need things done, without asking them to understand models or servers. Keep a separate builder/contributor path on the same page. Invite one task and a concrete success criterion. Publicly share actual results as they are verified. No invented testimonials, completed-job counts or autonomous income claims.
Paid help is accountable setup, integrations and infrastructure; the open core remains usable.
Launch message: We’re building 3DVR Operator: an open-source AI workspace you can make your own. Try it, bring one task, or help build the next milestone—reliable work that continues after you close your phone.

## Hosted product delivery
See [hosted product plan](operator-hosted-product.md). Shared server capacity is an internal implementation detail. Do not promise production multi-tenant isolation before it has been verified.
