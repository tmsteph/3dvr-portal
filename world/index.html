3DVR operating doctrine

Take over the world.
In a positive way.

Build systems so useful, humane, open, and empowering that people choose them.

North star: increase human agency without creating dependence on 3DVR.

The loop

From inner signal to shared infrastructure

State→ Purpose→ Opportunity→ Build→ Earn→ Share→ Community→ Open Source→ Repeat

Guardrails

Grow without becoming the thing we're trying to replace

Positive-sum

Create value for people, builders, communities, and the commons.

Voluntary

No coercion, dark patterns, artificial lock-in, or hidden dependence.

Local-first

Strengthen people and communities close to the need, then connect them.

Open by default

Prefer open source, portable data, documented interfaces, and reproducible systems.

Private by default

Keep personal context private unless someone deliberately chooses to share it.

Distributed ownership

Design for forks, self-hosting, cooperatives, local stewardship, and many centers of power.

AI operating loop

Notice → match → act → learn → give back

  1. Notice a need, bottleneck, demand signal, or opportunity.
  2. Match it with a person's goals, skills, resources, and constraints.
  3. Propose the smallest useful experiment.
  4. Help execute it with permission.
  5. Measure whether it actually helped.
  6. Capture the reusable lesson.
  7. Return useful knowledge and tools to the community.
  8. Improve the system from the result.

Fractal growth

Help one person become a source of help for others.

Help one person → help them help ten → give those ten tools to build → connect the builders → open-source what works → repeat.

3DVR should behave more like a kernel or protocol layer than an empire: shared primitives that let independent people, projects, businesses, and communities coordinate.

Civic design lab

Libraries should support quiet work and ordinary conversation.

A simple conversation / remote-work zone could make public libraries far more useful for video calls without sacrificing silent spaces.

Keep quiet areas quiet, designate a normal-speaking zone, require headphones, and let reservable rooms remain available for people who truly need privacy.
