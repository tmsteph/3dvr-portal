# Launch Room mobile UX

The mobile flow should optimize for one job: turn a rough idea into a useful brief without making the user read the whole product before starting.

## Principles

- Get to the first useful prompt immediately.
- One question at a time on small screens; full form on desktop.
- Keep mode selection visible but compact.
- Hide downstream output until the user generates the brief on mobile.
- Make the primary next action obvious: create a project draft or continue building.
- Keep all controls comfortably tappable and avoid iOS input zoom.
- Preserve local-first draft saving and existing desktop behavior.

## Current mobile structure

1. Compact Portal / Projects navigation.
2. Short Launch Room intro.
3. Mode selection.
4. Five-question guided flow with progress, Back, and Next.
5. Generate brief.
6. Brief and next actions.
