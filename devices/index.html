Device management

Pairing is not enabled yet

No hardware is connected by this page. Device enrollment, permission grants, revocation and live status require an authenticated backend. We won't simulate a connected device or store secrets in browser storage.

First build checklist

  1. Choose an ESP32 board, button and LED.
  2. Publish a minimal event/response protocol and threat model.
  3. Implement short-lived pairing and per-device revocable credentials.
  4. Test offline behavior and safe actuator defaults.
  5. Add authenticated device inventory and status.

Architecture: Open Hardware Operator proposal. Muse claims remain unverified.
