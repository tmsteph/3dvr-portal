Ubuntu Touch SSH bootstrap

mkdir -p ~/.ssh && chmod 700 ~/.ssh
wget -qO- https://portal.3dvr.tech/api/ut-pair >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
sudo systemctl start ssh.socket
[ -f ~/.ssh/utunnel ] || ssh-keygen -q -t ed25519 -N '' -f ~/.ssh/utunnel
K="$(base64 ~/.ssh/utunnel.pub | tr -d '\n')"
wget -qO- --post-data="key=$K" https://portal.3dvr.tech/api/ut-pair

Open reverse SSH tunnel

ssh -i ~/.ssh/utunnel -o BatchMode=yes -o IdentitiesOnly=yes -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -N -R 127.0.0.1:2206:127.0.0.1:22 root@167.233.174.20

This keeps a connection open from the OnePlus to Hetzner and maps Hetzner port 2206 back to the phone's SSH port 22.

Repair phone SSH

Generate host keys + restart SSH

sudo ssh-keygen -A
sudo service ssh restart || true
sudo systemctl restart ssh.socket
systemctl --user restart 3dvr-reverse-tunnel.service
systemctl --user status --no-pager 3dvr-reverse-tunnel.service

Use this if the reverse tunnel is up but connections through it close before the SSH banner appears.

Make it permanent

Keep the tunnel alive automatically

mkdir -p ~/.config/systemd/user
cat > ~/.config/systemd/user/3dvr-reverse-tunnel.service <<'EOF'
[Unit]
Description=3DVR reverse SSH tunnel

[Service]
ExecStart=/usr/bin/ssh -i %h/.ssh/utunnel -o BatchMode=yes -o IdentitiesOnly=yes -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -o StrictHostKeyChecking=yes -N -R 127.0.0.1:2206:127.0.0.1:22 root@167.233.174.20
Restart=always
RestartSec=10

[Install]
WantedBy=default.target
EOF
systemctl --user daemon-reload
systemctl --user enable --now 3dvr-reverse-tunnel.service
systemctl --user status --no-pager 3dvr-reverse-tunnel.service

Run this after closing the manual tunnel. It moves the connection out of Terminal so it can reconnect automatically.
