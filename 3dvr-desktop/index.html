Desktop environment

One 3DVR session, replaceable parts.

Openbox manages windows. Tint2 is the panel. Rofi launches apps. PCManFM handles files. Xterm is the baseline terminal. 3DVR owns the session defaults, install flow, launchers, and cross-device behavior—so these components can be swapped later without changing what “3DVR Desktop” means.

Daedalos remains the browser-native desktop. 3DVR Desktop is the native Linux desktop. The long-term goal is for them to feel like two runtimes of the same personal computer.
