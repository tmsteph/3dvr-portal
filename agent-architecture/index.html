Architecture rules

  • Provider threads are never the canonical memory.
  • Use the cheapest capable reasoning path.
  • Keep provider adapters swappable.
  • Log model, cost, latency, and outcome.
  • Escalate capability only when the task needs it.

Implementation direction

Digital Organism becomes the persistent intelligence layer.

The gateway sits between 3DVR Agent and model providers. ChatGPT can remain a useful interface, but the architecture must not depend on ChatGPT being the permanent home of context.
