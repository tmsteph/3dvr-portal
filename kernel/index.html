3DVR Kernel

3DVR should act more like the Linux kernel of business and AI development: a small, open foundation that many different products, organizations, agents, and interfaces can build on.

The kernel is the platform. The Portal is one distribution. AI operates the system instead of living inside one app.

Kernel

Goals, identity, permissions, memory, events, tasks, capabilities, policies, state, and agent coordination.

Portal distribution

Our opinionated user experience built on the kernel: Operator, CRM, Calendar, Forge, Launch Room, Revenue tools, and more.

Drivers

Adapters for Gmail, GitHub, Stripe, calendars, browsers, phones, servers, local computers, messaging, and future devices.

Userland

Apps and workflows can be replaced or remixed without rebuilding the underlying operating model.

System layers

Goals + policyWhat matters, what is allowed, what needs approval, and how success is measured.
Shared stateCurrent projects, people, tasks, context, finances, deployments, blockers, and system health.
CapabilitiesMachine-readable registry of what the system can do right now and how each capability is recovered.
OperatorThe coordinator. Chooses the highest-value next action and delegates work to the right agent or machine.
Agents + workersSpecialized services that research, build, communicate, deploy, monitor, and maintain.
AppsHuman-facing views into the same kernel state rather than disconnected silos.

Self-steering control loop

The Portal should continuously move work forward without waiting for a human to remember which app to open.

Observe→ Understand→ Prioritize→ Plan→ Act→ Verify→ Learn↺

Self-improvement loop

Software changes should use a protected improvement pipeline rather than unconstrained self-editing.

Notice friction→ Hypothesis→ Branch→ Build→ Test + eval→ Canary→ Measure→ Merge or rollback

Autonomous by default

  • research and summarize
  • organize state and documentation
  • run tests and health checks
  • repair low-risk internal failures
  • propose and validate code/UI improvements

Policy-gated

  • money movement and purchases
  • credentials and permission changes
  • destructive production actions
  • high-impact customer communications
  • changes that exceed configured risk limits

Kernel v0.1 milestone

Goals + State + Capabilities + Events + Policies + Agent Loop + Evals + Rollback

New Portal features should increasingly plug into these primitives instead of creating isolated state and one-off automation.

North star

3DVR is an open kernel for autonomous organizations.

The Portal is our reference distribution. Other people should eventually be able to build entirely different businesses, communities, and AI systems on the same kernel.
