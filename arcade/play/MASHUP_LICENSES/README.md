# Mashup asset licences

The sm64js engine code is WTFPL (see ../LICENSE). Super Mario 64 textures/sounds are NOT in this repository: they are
extracted at runtime from the player's own ROM in the browser. Every guest asset added by the mashup is free-licensed and
embedded directly; one folder per donor game:

- freedoom/   - Doom zombieman (Freedoom, BSD-3-Clause) - slice 1, licence in /workspace/mashup/assets/freedoom/LICENSE
- supertux/   - Mr. Iceblock, Snowball, Mr. Bomb, Fire Flower, Ice Flower, fire/ice bullets (GPL-3.0-or-later / CC-BY-SA)
- blasphemer/ - Ghoul, Harpy (BSD-3-Clause)
- supertuxkart/ - Tux in his kart, real 3D model (GNU GPL)
- librequake/ - Rottweiler (dog) + Ogre, real 3D vertex-animated models from Quake MDL (BSD-3-Clause)
