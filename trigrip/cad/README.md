# TriGrip mechanical proof of concept v0.1

Open `trigrip-v0.scad` in OpenSCAD and render/export STL. Units are millimeters. This is a **flat-print parts layout**, not a finished functioning collapsible assembly: three 70 mm pivot arms, triangular hub plate, and spacers. Requires M4 fasteners, washers, and testing. Hinges currently have no locking detents; telescoping arms, belt retention, keyboard dock, phone attachment and load ratings are not yet engineered.

Test with dummy loads before attaching a phone. Check pinch hazards, bolt clearance, finger comfort, foldability, phone hinge/camera clearance, and sharp edges. Do not rely on this prototype for overhead or wearable mounting.
