Portrait + software keyboard: natural phone use with useful workspace above the lower-third keyboard.

Core interaction

The dock follows the task.

3DVR should not force one screen orientation. The holder rotates 90° without removing the phone, while the controls and grip remain usable.

01

Portrait + software keyboard

Default phone mode. The on-screen keyboard can occupy the lower third while the upper two-thirds remain useful for messages, Operator, browsing, and forms.

02

Landscape + physical keyboard

Once real keys are available, the screen no longer needs to reserve a lower third. Landscape becomes a tiny workstation with the full display available for the actual task.

03

Landscape + controls

Game, camera, Pocket Window, remote desktop, spatial computing, and media modes can prioritize thumb controls, shoulder buttons, trackpoint, trackball, or sticks.

Design rule Soft keyboard present → portrait is usually better. Physical keyboard present → landscape becomes practical and often preferable.

Input system

The holder becomes the computer around the computer.

Start mechanical, then add only the controls that prove useful. The phone remains replaceable; the dock becomes a long-lived input and expansion platform.

Keyboard

Thumb typing or fold-out keys

Split keyboard halves can live beside the phone, fold behind it, slide underneath it, or detach for desk use.

Pointer

Trackpoint / trackball / touch

A precise pointer makes remote desktop, code, web apps, and desktop UI possible without reaching across the screen.

Controls

Sticks + shoulder buttons

Optional gamepad-style inputs also work for camera movement, spatial navigation, scrolling, media, and 3DVR worlds.

Dock

USB-C expansion

Charging, audio, storage, keyboard, Ethernet, display-out, and future compute modules all converge through one replaceable dock layer.

Prototype v0

Mechanical first.

The first useful version does not need custom electronics. It needs to prove rotation, grip, keyboard position, phone compatibility, balance, and the transition between handheld and desk use.

Adjustable clampFits common phones with or without a slim case.
90° rotationPortrait ↔ landscape without removing the phone.
Stationary gripThe phone rotates; the control surfaces do not have to.
Keyboard bayUse an existing Bluetooth/USB keyboard first; custom split keys later.
Fold-out standHandheld hardware becomes a stable desk workstation.
USB-C pass-throughPreserve charging/data from the beginning.

The older grip, stand, tripod, extender, lap, strap, and AR-glasses ideas are not discarded. They become mounting modes for the larger Phone Dock system.

Build path

Prototype the ergonomics before the electronics.

  1. 1
    Cardboard / foam / existing phone clamp

    Test portrait-to-landscape rotation, hand spacing, center of gravity, and whether controls should sit beside or below the phone.

  2. 2
    3D-printed adjustable frame

    Add quick release, rubber padding, a fold-out stand, shoulder-button geometry, and 1/4"-20 mounting points.

  3. 3
    Off-the-shelf keyboard + pointer

    Integrate a small Bluetooth/USB keyboard and trackpoint, trackball, or thumb pointer before designing custom PCBs.

  4. 4
    3DVR modular input rail

    Standardize swappable keyboard, gamepad, trackpad, macro, battery, storage, and compute modules.

  5. 5
    Open hardware release

    Publish printable parts, dimensions, electronics, firmware, and lessons learned so the dock can outlive any single phone.
