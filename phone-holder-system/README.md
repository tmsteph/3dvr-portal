# 3DVR Phone Dock / Phone Holder System

The existing `/phone-holder-system/` concept has evolved from the original 3DVR Nomad Clip into the broader **3DVR Phone Dock**: a universal holder, physical-input system, dock, and pocket workstation built around the phone the user already owns.

## Core design rule

- **Software keyboard visible:** portrait is usually the natural default because the keyboard can occupy the lower third while useful workspace remains above it.
- **Physical keyboard available:** landscape becomes practical because the full display can be reclaimed for the task.
- **Spatial / game / camera controls:** landscape can prioritize sticks, trackpoint/trackball, shoulder buttons, and other physical inputs.
- The phone holder should rotate 90° without requiring the phone to be removed.
- **One cradle, many mounts:** belt, chest, head/VR, desk, tripod, bike, and future mounts should share one quick-release geometry.
- **Movement needs positive retention:** magnets may align the dock, but wearable modes require a mechanical catch or safety tether.

## System direction

The phone remains the screen, camera, sensors, cellular connection, and compute node. The surrounding dock provides ergonomics and long-lived hardware:

- adjustable phone clamp
- portrait / landscape rotation
- stationary ergonomic grips
- split, fold-out, slide-out, or detachable keyboard options
- trackpoint, trackball, touch, sticks, shoulder buttons, and macro controls
- USB-C power/data/display pass-through
- fold-out desk stand
- reversible belt clip
- stabilized neck / chest harness
- balanced head / VR mount with a flip-up or floating-screen position
- external monitor / TV / projector / AR-glasses support
- future modular battery, storage, and compute attachments

The original **Nomad Clip** ideas remain useful as mounting modes: grip, stand, tripod, extender, body clip, lap setup, and wearable/AR routing.

## Wearable direction

The Phone Dock should move with the person through several postures:

- **Belt clip:** secure low-profile carry, reversible screen direction, one-hand quick release.
- **Neck / chest:** mount the phone high enough to glance at and use a second stabilizer point so it does not swing.
- **Head / VR:** support both immersive viewing and a lower floating-screen position. Move battery/counterweight mass rearward when useful.
- **Public transit:** personal theater/terminal mode with headphones and lap keyboard/controller input.
- **Walking:** preserve situational awareness. Favor audio, quick glances, peripheral vision, and flip-up hardware rather than opaque VR while moving through public space.

The shared mounting interface is the important standard: magnetic alignment for convenience, positive mechanical retention for safety, rotation for portrait/landscape, and open dimensions so new accessories can be printed or manufactured independently.

## Prototype path

Start mechanically before building custom electronics:

1. Cardboard/foam + existing phone clamp to validate orientation, grip spacing, and balance.
2. 3D-printed adjustable cradle with the shared quick-release interface.
3. Build simple belt, chest, desk, and head adapters around the same interface; test bounce, comfort, balance, retention, and one-hand removal.
4. Integrate an off-the-shelf Bluetooth/USB keyboard and pointer.
5. Standardize a modular 3DVR input rail for keyboard, gamepad, trackpad, macro, storage, battery, and compute modules.
6. Publish printable parts, dimensions, firmware, and electronics as open hardware.
