Public roadmap

The direction stays visible.

We may not know every processor, enclosure, or release date yet. We can still be clear about where Open Personal Computing is going: use the best repairable hardware available now, build an owner-controlled software and hardware layer next, and open more of the stack over time.

Now → Next → Later
NowRepairable reference hardware, Linux, Portal, 3DVR OS.
NextModular devices, documented interfaces, user-owned intelligence.
LaterOpen RISC-V compute, reproducible boards, deeper supply-chain control.
Long-termA personal computing commons people can understand, repair, fork, and keep.

First device

3DVR Laptop

The laptop should outlive the compute board inside it. We are separating long-lived parts—display, keyboard, battery, storage, ports, and enclosure—from the faster-moving processor generation.

Open silicon path

3DVR RISC-V

A small FPGA-first SoC project: open CPU, memory and interconnect, a simple accelerator path for tinygrad, and Linux from the beginning. The goal is a computer stack we can understand end-to-end.

Open mobility

3DVR Open Vehicle

Extend the same repairable, owner-controlled philosophy beyond the laptop: open diagnostics, modular compute, documented hardware, local-first software, and a path from safe retrofits toward a genuinely open vehicle platform.
