# 3DVR Compute

Open personal computing hardware: modular, repairable, Linux-first, and increasingly open all the way down.

The first device is the 3DVR Laptop, a continuation of the modular, repairable ideas explored by the Balthazar project.

## Design rules

- Keep the first screen simple and product-focused.
- Prefer links that go somewhere useful over same-page navigation.
- Separate long-lived laptop parts from replaceable compute generations.
- Prototype with real available boards before designing new silicon.
- Document closed dependencies rather than pretending the stack is already fully open.
- Connect hardware choices to the Open Supply Chain registry.
